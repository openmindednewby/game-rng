# Changelog

## 1.0.0 - 2026-10-08

- First release. `mulberry32`, `hashString` (FNV-1a), `createRng(number | string)`, `range`, `pick`, `dailySeed`, `randomSeed`.
- Bit-identical to `Surge/src/rng.ts` (golden vectors in `src/goldenVectors.json`, regenerated by `npm run golden:generate`), and to Aurora's `seededRandom` (`src/boot/beginRealmMotes.ts`) and `makeRng` (`src/audio/ambientPlan.ts`).
- `pick` on an empty list throws `RangeError` (Surge returned `undefined`).
